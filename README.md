# NutriTrack Challenge

React Native implementation of the NutriTrack nutrition dashboard challenge.

## Technologies

- React Native
- Expo
- TypeScript
- Expo Router

## Features

- Nutrition summary
- Calorie progress
- Macro progress bars
- Meal list using mock data
- Add Meal component
- Log Food button
- Bottom navigation

## Running the project

Install dependencies:

npm install

Start the project:

npx expo start

For web:

npx expo start --web
