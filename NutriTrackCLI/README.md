# 🥗 NutriTrack Challenge

Technical challenge implementation of a nutrition dashboard using **React Native CLI and TypeScript**.

## 🚀 Implementation

The project includes:

* React Native CLI
* TypeScript
* Reusable component architecture
* TypeScript interfaces
* Mock nutrition and meal data
* Calorie and macronutrient progress indicators
* Meal cards
* Bottom navigation
* Android native project

### Project

The React Native CLI implementation is located in:

```text
NutriTrackCLI/
```

To run the application:

```bash
cd NutriTrackCLI
npm install
npm start
```

In another terminal:

```bash
npm run android
```
